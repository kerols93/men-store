# MAN — Men's Fashion Luxury Dark E-Commerce Store
واجهة متجر إلكتروني متكاملة للملابس الرجالية الفاخرة باللون الأسود الملكي

> **متجر إلكتروني Front-End احترافي، عصري وسريع، متجاوب 100% مع الهواتف الذكية ومربوط مباشرة بتطبيق واتساب وجوجل شيت بدون أي اشتراكات شهرية أو سيرفرات معقدة.**

---

## ✨ المميزات الرئيسية للمتجر (Core Features)

1. **تصميم ملكي داكن (Pure Luxury Black):**
   - لوحة ألوان سوداء فخمة (`#0a0a0c`, `#121215`, `#16161b`) مع لمسات برونزية راقية وخط Cairo العربي الحديث.
   - تأثيرات بصرية سينمائية، ونوافذ معاينة سريعة للمنتجات (Quick View Modal).

2. **الربط الديناميكي مع Google Sheets عبر Fetch API:**
   - قراءة وتحديث المنتجات والأسعار والصور والأقسام مباشرة من شيت جوجل بدون أي تعديل في الكود.
   - دعم عرض سعرين لكل منتج (السعر الحالي + السعر قبل الخصم مع حساب شارة الخصم تلقائياً).

3. **نظام الكوبونات الذكي (Dynamic Coupons Engine):**
   - إدارة كاملة لأكواد الخصم من تبويب خاص في جوجل شيت (إضافة كود، تحديد نسبة الخصم %، تعيين حد أدنى للطلب، وإلغاء/تفعيل الكود بكلمة واحدة).
   - حماية منطقية كاملة: إلغاء الكوبون تلقائياً إذا انخفضت السلة عن الحد الأدنى.

4. **تكامل متكامل مع السوق المصري وتطبيق WhatsApp:**
   - نموذج تأكيد طلب احترافي يشمل كافة محافظات مصر وخيارات الدفع (عند الاستلام أو إنستاباي / محفظة ذكية).
   - تحقق صارم من صحة رقم الهاتف المصري (11 رقماً تبدأ بـ 01).
   - توليد رسالة واتساب منسقة وتفصيلية تُرسل فوراً إلى رقم المتجر `01011695927`.
   - توثيق الطلب تلقائياً في شيت "الطلبات" بجوجل شيت في الخلفية.

5. **تجربة مستخدم استثنائية على الهاتف المحمول (Mobile-First):**
   - قائمة تنقل جانبية منبثقة (Hamburger Navigation Drawer).
   - زر واتساب عائم ونبّاض في أسفل الشاشة للتواصل السريع مع خدمة العملاء.
   - حفظ حالة السلة تلقائياً في التخزين المحلي (`localStorage`).

## 📁 هيكلية ملفات المشروع (Project Structure)

```text
├── index.html       # هيكل الصفحة وعناصر المتجر (HTML5 الدلالي)
├── style.css        # التنسيقات والألوان والتجاوب الكامل (Responsive CSS)
├── app.js           # منطق المتجر، التفاعل، السلة، الكوبونات والربط
├── Code.gs          # كود Google Apps Script لتحويل بيانات الشيت إلى JSON
└── README.md        # دليل المشروع والتوثيق
```

---

## 🚀 طريقة التشغيل والربط السريع

1. افتح شيت جوجل وضع به بيانات المنتجات والكوبونات.
2. ضع كود `Code.gs` في **Apps Script** وانشره كـ **Web App**.
3. ضع رابط الـ Web App في متغير `GOOGLE_SHEET_API_URL` أعلى ملف `app.js`.
4. ارفع الملفات إلى أي استضافة ثابتة مجانية مثل **Netlify** أو **GitHub Pages**.
